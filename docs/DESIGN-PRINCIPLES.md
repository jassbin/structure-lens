# 解忧果（Structure Lens 小程序版）· 设计原则

> 本文是「照妖镜 / 解忧果」系列产品的**设计原则补充**，与仓库原有 `docs/METHODOLOGY.md`（原 Web 版的方法论）互补。原版 Web 形态保留；本文描述的是演进到微信小程序「解忧果」后沉淀下来的原则。

## 0. 一句话定位

> 把结构性困局里的「看清」变成「可动」：不美化痛苦、不灌鸡汤——能改的去改，改不了的学会不骗自己地调节。

- Web 版回答「这件事到底是怎么运作的」（看清结构）。
- 小程序版接续回答「那我今天能做什么」（给出行动），并把「看清 → 可动」做成闭环。

## 1. 认知层原则

### 1.1 可证伪优先于自洽
- 一个结论如果无法给出「出现什么就说明我错了」，它就不配成为核心判断。
- 8 步流水线（材料 → 异常 → 骨架 → 机制 → 博弈 → 情景 → 判断 → 对抗质检）是**可证伪纪律**的落地：每一步都要能停下来追问与反驳。

### 1.2 结构优先于表象
- 单单把事件讲清楚不够，要把它还原成**主体 / 对象 / 机制 / 受损方 / 受益方**的骨架，再找树根结构（提取-分配 / 委托-执行 / 权力竞争-均衡）。
- 「原本以为是」与「真实运作是」之间的**落差坐标**，是我们唯一用来推导缝隙的地方。

### 1.3 痛是信号，不是命运
- 把情绪痛还原成冷静的信号：是身体的生物警报（怕、累、被挑战），还是被某个刚性结构挤压的结构信号。先看清真正在痛什么。

### 1.4 诚实优先
- 不美化痛苦、不灌鸡汤、不装知道、不给「情绪安慰剂」当真理。
- 搜不到就说不搜不到；「部分采纳」就讲清哪点成立、哪点不成立。

## 2. 行动层原则（清醒行动主义 → 六步引擎）

1. **痛点定位**：痛 = 信号，不是命运。
2. **可控性分诊**：逐条拆开归入三筐——能改环境 / 能改自身 / 暂时不可控。可控/不可控是试探后的结果，不是先验断言。
3. **自欺检测**：区分「能动而不动」与「真的动不了」（伦理闸门）。前者温和点破，后者共情而不催促。
4. **最小行动**：只对「能改」的部分给今天或本周就能起步的试探（5 分钟可开始、可迭代）。行动产生反馈，反馈打破自欺。
5. **缝隙扫描**：针对暂时动不了的结构，只从「落差坐标」找现实缝隙（规则不一致、监督空白、利益裂痕、新空间）。
6. **清醒安慰剂**：对「确实改不了」的部分给不自欺的调节法（生理优先、观察者练习、限定反刍时间）。它是止痛，不是治本。

### 单步追问的增量级联
- 每一节都可以「我不同意 / 追问」；采纳后**被问的那节及其下游所有受影响章节必须联动更新**，不允许出现「只改当前步、后面自相矛盾」。
- 辩论留痕全部可见（对方如何回答、站在吸收/折中/维持哪一种立场），让用户随时可以回到任意一轮。

## 3. 交互设计原则

### 3.1 轻重表达
- 核心步骤（核心机制、核心结论、中性骨架）用「关键卡 + 角标」强调；辅助步骤（博弈、情景）弱化，降低长报告的阅读负担。
- 每一节都配「?」注释，把术语翻译成口语。

### 3.2 追求诚实负载的体验
- 长任务（生成/追问）用**乐观进度 + 阶段清单 + 预估剩余**，而不是死海的 spinner；瞬时失败自动重试，特殊不闪大清屏。
- 字段缺失怪显示「—」与占位文案，绝不显示空白卡或触发渲染崩溃。

### 3.3 可恢复
- 生成失败可原样重试；报告与行动方案本地记忆，结构未变时直接复用，避免重复烧钱。

## 4. 工程原则

### 4.1 免登录优先
- 小程序用 `wx.login` 静默 + 云托管自动注入 openid 实现「无感登录」；不要求注册、不显示登录按钮，把使用摩擦降到零。
- 前端永不持有 AI Key/密钥；密钥只存于服务端环境变量。

### 4.2 异步长任务
- AI 长任务（分析 30-60s、行动方案 20s+）一律走 `taskId 提交 + 轮询`，绕开 `wx.cloud.callContainer` 15s 硬超时；轮询上限给足余量并允许自动重试。

### 4.3 双视图、单份数据
- 行动方案同时有「六步行动」与「五模块推演」两套视图，共享同一份数据；任何一次重算/视角切换后两套视图自动同步，避免自相矛盾。

### 4.4 版本对齐
- 前端版本号与后端版本号**总是同一位**（例如 前端 1.0.36 ↔ 后端 v21.5），`/healthz` 返回后端版本，避免「版本管理页时间相同搞不清哪个新」。
- 改任何端内容即升号，不复用旧号。

### 4.5 部署与验证
- 流程极简：本地验证跑通 → 一键全量部署 → 一次 `healthz` 冒烟收工；小改动不反复多轮验证浪费时间。
- 治标（自动重试/冷启动预热）与治本（云端至少 1 个实例常驻）同时做。

## 5. 隐私原则

- 默认不采集任何用户隐私：不要求手机号、昵称、通讯录、位置。
- 唯一可能触碰的个人信息管理接口：**剪贴板**——仅用于用户在分享页「主动点复制」文案，绝不自动读写剪贴板。
- 分析数据默认本地保存，用户可主动把本地分析并入云端结构地图（仅用于同源结构聚类）。
